# B 站扒网课 SOP（魏老师备课用）

目标：把一节 B 站数学网课扒成「她备课能直接用、可溯源」的笔记，入 DeepTutor「魏老师-数学」资料库。

## 0. 工具

- **bili-watch 插件**：查视频信息、取字幕、抽帧（装法见 `插件目录.md`；工具名 `bili_watch`）
- **本包转写脚本**：`python bin/asr-sensevoice.py`——App 自带的 SenseVoice 模型，本机离线，约 4–5 倍实时；需要 `ffmpeg`、`yt-dlp`
- **抽帧**：`bili_watch` 的抽帧/拼图能力，直接看图读板书、PPT、题目

## 1. 选源

- 她给链接（`b23.tv` 短链也行）或 BV 号；没有就按主题搜（如「一数 数列」）。
- 先查清：标题、UP 主、分 P、每 P 时长、发布日期。优先 2023 年后的（多数字幕）。
- 一句话跟她确认范围：讲哪一章、要几篇笔记（一篇一个主题，别一锅炖）。

## 2. 先查字幕（省时间）

- `bili_watch` 查该视频有没有字幕，有就直接取全文，不跑 ASR。
- 字幕是机器转的，公式常错：`建系→间隙`、`θ→C塔`、`焦点→交点`、`aₙ→AN`、负号被吞、数字错位。成稿前按数学常识还原，还原不了整句不写。

## 3. 没字幕 → 本机转写

- 整 P：`python bin/asr-sensevoice.py --bv BV1xxxx --p 3 --out /tmp/网课.txt`
- 只取一段：加 `--start 0:00 --end 10:00`
- 20 分钟以上拆 2–3 段跑，别一次怼 1 小时（会慢、会爆内存）
- 模型路径按 `DSH_HOME` 自动找；报「模型不存在」就先在 App 里启用语音输入，把 SenseVoice 模型下下来。

## 4. 画面/板书（语音拿不到的）

- 抽帧看关键板书、PPT、角标、题号；字小看不清就放大局部。
- 印刷体可用 OCR 交叉核对；手写板书 OCR 一般，以看图为准。
- 角标、小字、图上的标注是转写拿不到的信息，**必须看图**，别只靠文字稿。

## 5. 成文（严格按 `kb/notes/_规范.md`）

- 每节：核心（定义/公式/二级结论）→ 怎么讲（讲课顺序、板书要点、学生容易卡哪）→ 例题 → 易错
- 每节至少一条 `[来源 BV... P... mm:ss]`，时间码从字幕/稿子里取，不许估
- 1500–3000 字；Unicode 数学符号；禁 LaTeX
- 文末：覆盖清单 + 来源表；没覆盖的小节写 ❌ 并说明

## 6. 入库

```bash
deeptutor kb add 魏老师-数学 --doc <项目目录>/kb/notes/<文件>.md   # 多文件就多个 --doc
deeptutor kb search 魏老师-数学 "关键词"                          # 验收能搜到
```

- 批次多的用 `--docs-dir <项目目录>/kb/notes/`
- 验收：问她一个只有这节网课里才有的问题，看引用对不对

## 7. 回她一句人话

「这节收进去了，主要讲 X、Y，我标了 Z 处要你核实；以后你问到 X 我能直接引。」

## 坑（血泪）

- 字幕/转写里的数字、下标、负号最容易错，公式必须回归数学常识
- 不整段搬字幕原文；笔记是提炼，不是转录
- B 站内容有版权：只做她自用笔记，不往群里、家长群传
- 网课讲法跟教材/她的教案打架时，标出来问她，别自己定
- 同名笔记别覆盖，先问
