# B 站网课 → 备课笔记 → 资料库

详细流程见 `kb/notes/_扒课SOP.md`，笔记格式硬规矩见 `kb/notes/_规范.md`。本技能只列动作顺序和红线。

## 触发

她发来视频链接、`b23.tv` 短链、BV 号，或者贴一个合集，说「扒一下 / 看看讲了什么 / 收进资料 / 备这节课用」。

## 步骤

1. **确认范围**：讲哪一章、对应课本哪节、要几篇笔记（一篇一主题）。一句话问清，别自己猜。
2. **取材料**
   - 用 `bili_watch` 查标题、UP 主、分 P、时长、有没有字幕；有字幕先取全文（2023 年后多数字幕）。
   - 没字幕才转写：`python bin/asr-sensevoice.py --bv BVxxxx --p N --start 0:00 --end 30:00 --out /tmp/x.txt`（长视频分段）。
   - 板书、公式、角标、图上标注：抽帧看，字小就放大；印刷体可 OCR 交叉核对。
3. **核对**：数字、下标、字母按数学常识还原（「十3」=13、「AN」=aₙ、「C塔」=θ）；错得离谱的句子不写。
4. **写**：H1 + 每节「核心 / 怎么讲 / 例 / 易错」；每个知识点标 `[来源 BV... P... mm:ss]`；文末覆盖清单 + 来源表。禁用 LaTeX，数学用 Unicode，1500–3000 字。
5. **质检**：每节有来源；无 LaTeX；覆盖清单如实；网课与教材/她教案冲突处标「待核实」。
6. **入库**：`deeptutor kb add 魏老师-数学 --doc <项目目录>/kb/notes/<文件>.md`，再 `deeptutor kb search 魏老师-数学 "关键词"` 验收。
7. **回她人话**：这节讲了什么、收进哪了、有几处要她核实。

## 红线

- 只写视频讲到的；没讲的不补、不猜。
- BV 号、分 P、时间码必须真能对上，不许估。
- 不整段搬字幕；笔记是提炼。
- B 站内容有版权：只做她自用笔记，不往班级群 / 家长群传。
- 不覆盖她已有的笔记；同名先问。
